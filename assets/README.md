# A0 应用图标工程资产

`app-icon.svg` 是 1024×1024 的正式矢量母版，画布透明；深海军蓝底板为 `x=32`、`y=32`、`960×960`、圆角半径 `190`。图标不使用阴影、外发光或嵌入位图。

正式母版使用克制的双端线性渐变：

- 底板：`#052544` → `#082e54`
- 左上：`#ffffff` → `#f3f7fb`
- 左下：`#62c2fa` → `#3e9eea`
- 右上：`#2488ff` → `#126bf0`
- 右下：`#22e4df` → `#0bc8c6`

16/24 px 图层保留同一几何轮廓，改用无渐变纯色 `#07294d`、`#f8fbff`、`#4daef2`、`#1677ff`、`#14d5d1`，避免小尺寸色带和边缘噪声。32/48/64/256 px 直接从正式母版渲染。

在已具备项目固定依赖的环境中重建 ICO：

```powershell
python -B scripts/generate_app_icon.py
```

生成的 `app-icon.ico` 同时用于 Qt 应用/窗口图标、portable 只读资源和 PyInstaller EXE 图标。不要从交接 PNG 裁剪或覆盖母版。
