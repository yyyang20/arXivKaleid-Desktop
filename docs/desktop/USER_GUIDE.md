# 使用说明

了解操作流程、两轮筛选和提示词设置。

## 开始使用

1. 在[设置](arxivkaleid://settings)中配置 API。
2. 在[提示词](arxivkaleid://prompts)中设置两轮研究目标，并保存。
3. 返回[首页](arxivkaleid://home)，抓取今天或指定日期的候选论文。
4. 开始两轮分析，完成后查看日报；过去的日报可在[历史](arxivkaleid://history)中查看。

## 抓取日期与版本

日历可选择今天及此前 365 天的北京时间日期；选日期后点击抓取按钮才联网。当前固定查询 `gr-qc`、`astro-ph.HE`、`astro-ph.GA`。

首页及抓取详情的日期、完成时间标签均标明“北京时间”；完成时间显示为 `YYYY-MM-DD HH:MM:SS`。

日期决定具体版本：例如 1 月 1 日提交 v1、2 月 1 日提交 v2，后来再查询 1 月 1 日仍取 v1。当天没有新版本则不出现，同一论文当天多个版本只用最后一版。这里是提交日，不是 arXiv 公告日；尚未公开或尚未更新到服务的数据暂时不可见。

重复抓取会联网刷新，只把校验成功的全部候选保存到本地版本元数据库，供后续复用；不是只保存模型推荐论文。后续分类迁移可能导致首次回抓漏发现，但不能用最新版替代已发现的历史版本。读取历史日期可能较慢，因为需要完整遍历所查分类自目标日起更新的历史记录；失败不返回部分成功，也不自动重试。

PDF 与摘要绑定同一明确版本；旧缓存没有版本来源证据时不会直接复用。过去保存的日报保持原内容，不受以后版本更新影响。

## 两轮筛选有什么区别

- **第一轮**：根据论文标题和摘要筛选，不要求研究排序。
- **第二轮**：根据标题、摘要和通过门控的 PDF 提取全文筛选，由模型按提示词要求排列推荐顺序。
- 第二轮不继承第一轮的评价或顺序，独立判断本轮论文。

第一轮没有入围论文，或没有合格全文时，不调用第二轮。

## 如何设置提示词

研究方向、数量、筛选边界和评价要求均可修改；第二轮还可设置排序依据。

默认提示词建议第一轮最多 10 篇、第二轮最多 5 篇。**这些数字可以修改，程序不会按默认的 10／5 篇额外截取结果。**

实际入选由模型根据提示词判断，允许少选或零选，**不要求选满**。

修改后请点击“保存”，保存内容用于下次分析，重启后仍保留。“取消”不保存本次修改，“恢复默认”可找回内置模板。

分析期间提示词只读，分析结束后可继续编辑。

## 如何阅读日报

第一轮以“论文 1、论文 2……”编号，编号不代表研究排名。

第二轮以“Rank 1、Rank 2……”显示模型返回的推荐顺序，程序不自行评分或重新排序。

日报保留论文信息、评价、PDF 页数、链接及 Token 和费用记录。论文链接可用于打开摘要页和在线 PDF。

历史保存当次日报；之后修改提示词，不会改写已有历史内容。

## 资源与费用

PDF 超过 **60 页**，或下载、全文提取失败的论文，不进入第二轮。

PDF 全文由 `pypdf` 提取，并非原始 LaTeX。公式、上下标及复杂排版可能失真，阅读评价时应注意这一限制。

程序保留 Token、上下文和费用保护。第一轮输入超限时停止分析；第二轮全文总量超限时，可能先排除部分论文再分析。

**分析会产生模型调用费用。** 开始前请确认 API 配置及两轮提示词，实际 Token 用量和费用可在日报中查看。
