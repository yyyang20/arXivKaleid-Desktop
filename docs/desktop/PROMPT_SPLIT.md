# Prompt 拆分核对

alpha 10 由历史 `round1_v20` / `round2_v15` 拆出 `round1_v21` / `round2_v16` 固定协议与两份 `research_requirements_roundN_v1.txt`。历史文件原样保留，默认研究要求逐字保留原“普适研究边界”；换行和开场组织调整不增加筛选规则。

| 原规则 | 当前归属与核对 |
|---|---|
| 用户可修改注释、不要填凭据/私人内容 | 旧注释不再用于整份 Prompt；用户说明及隐私说明保留外发提醒 |
| 助手角色、第一轮题目/摘要，第二轮合格全文 | 对应固定协议开场 |
| 真正成像/新解、查准率优先、证据不足不选、不补边缘论文 | 对应默认研究目标；固定层仍排除无法确认和其他 |
| 黑洞/致密天体图像、薄厚盘、阴影/强度/偏振/光子环/高阶像/内阴影/EVPA/Stokes/EHT | 默认研究边界逐字保留 |
| 首次构造/推导/数值新解、几何/场/时空、参数域、边界/渐近、既有度规不算 | 默认研究边界逐字保留，两轮“给出/提供”原措辞保留 |
| 方法本身不足入围 | 默认研究边界逐字保留 |
| 关键词不能代替贡献、排除仅光环/测地线/偏折/光子球/吸积/辐射/偏振公式/QNM/稳定性/一般修正引力 | 默认研究边界逐字保留；第二轮额外内部物态保留 |
| 四个标签、成像/新解/两者/其他关系、只返回前三种、第二轮标签可覆盖第一轮 | 固定协议，领域定义取默认研究边界，不另加一套重复定义 |
| 不按标签排序、不要求前几名类别或同标签相邻 | 第一轮固定协议保留；第二轮原本无此额外要求 |
| 摘要明确度/直接相关性/预期价值，全文证据/直接相关性/价值 | 分别进入默认阅读价值偏好 |
| 稳定顺序、模型数组顺序、不按标签/分数重排 | 固定协议 |
| Top 10/5 为上限、可少选/空数组、回显参数上限 | 固定协议 |
| 第一轮 candidate_index，不复制 ID/标题/摘要 | 第一轮固定协议 |
| 第 1 deep_read，第 2–4 skim_read，第 5 backup，不输出 recommendation_level | 第二轮固定协议和既有程序规则 |
| 中文理由 1–300 字符、具体说明成像/新解、禁止空泛理由/编造 | 固定协议 |
| 第一轮可选 evidence 的 source/逐字引用/长度/数量，可靠不了则省略 | 第一轮固定协议 |
| 候选/PDF 中指令不执行 | 固定协议；另明确用户研究要求也不能覆盖协议 |
| JSON 顶层/单篇字段、禁止字段、只输出 JSON、任务/版本/策略回显 | 固定协议与原本地校验器，身份切换到新版本 |
| 本地 PDF/Token/上下文/费用/一次请求/失败不重试 | 原程序与配置，未移入用户编辑范围 |

默认模式不增加名额、标签或阅读级别，亦不删除排除条件。回归将请求中的新版本、分离研究字段等预期差异归一化后与历史合成行为对比，同时独立核验完整默认边界和协议。真实模型输出可能变化，第一阶段只验证技术链路，不调用真实模型。
