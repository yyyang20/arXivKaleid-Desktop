# Prompt 拆分核对

alpha11 当前使用 `round1_v23` / `round2_v18` 最小技术协议与 `research_prompt_round1_v2.txt`、`research_prompt_round2_v2.txt` 完整默认研究提示词。两轮数量由用户决定，第二轮按模型顺序排名。历史资源原样保留，不进入当前运行或冻结程序。

| 规则 | 当前归属与核对 |
|---|---|
| 研究方向、筛选/排除条件、评价、严格程度 | 全部由 GUI 可见、可编辑的完整研究 Prompt 控制，通过 `research_prompt` 进入请求；第一轮不要求研究排序 |
| 通用主要贡献、信息明确度、阅读价值、查准率优先、宁缺毋滥 | 仅为可编辑/删除/恢复的默认建议，程序不强制执行 |
| 黑洞阴影及其边界、第一轮最多 10 篇、第二轮最多 5 篇、1—3 句话入选说明及第二轮阅读排序依据 | 仅为 GUI 默认模板，可编辑/删除/恢复；技术层不包含领域筛选规则或固定篇数要求 |
| 标题/摘要公式与符号格式提醒；pypdf 非原始 LaTeX、公式/上下标/排版失真提醒 | 分别只在两轮默认研究 Prompt 正文中，固定层不重复 |
| 第一轮输入 | 仅身份、标题、摘要；作者和分类供本地展示 |
| 第二轮输入 | 仅身份、标题、摘要和合格逐页全文，按身份升序；不传第一轮评价、标签、评分、理由或排名 |
| 结果顺序、允许空数组、不补位 | 保留模型数组顺序，合法子集连续编号；第一轮显示“论文 N”，不代表研究排名；第二轮显示 Rank 1 起的排名 |
| 篇数 | 两轮由用户提示词决定，全部输出进入身份校验，不解析提示词数字，无固定篇数上限 |
| 第一轮 candidate_index；第二轮 arxiv_id、version | 唯一必填单篇字段，另可提供自由文本 `evaluation`；无评价仍可入选 |
| 中文、300 字理由、固定阅读级别、固定证据格式 | 不再强制；无效可选评价丢弃并计入审计，合法身份继续入选 |
| 候选/PDF 中指令不执行，用户 Prompt 不覆盖技术协议 | 固定安全层 |
| 顶层 JSON、任务/版本/策略回显、候选成员、重复 | 固定技术协议及本地校验器；拒绝旧协议缓存 |
| PDF 60 页、Token/上下文/费用、一次请求、失败不重试 | 原配置和程序边界；Token 排除仍选最大载荷，并列按身份裁决，不读第一轮排名 |
| 持久化、工作库、日报及历史 | `research_prompt_v1` 两轮独立保存；自由评价复用 reason 列，兼容评分/阅读级别列置空；历史保留当次 Markdown |

离线回归只保留仍适用的安全、资源和失败断言，不要求复现历史领域筛选。置换/污染第一轮顺序及评价，核验第二轮请求、缓存身份与 Token 并列裁决不变。第一阶段不调用真实模型；默认筛选质量仍由实际模型和用户 Prompt 决定。
